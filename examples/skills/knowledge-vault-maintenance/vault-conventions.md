# Knowledge_AI_Engineering conventions

Reference: [the vault README](https://github.com/speillet/Knowledge_AI_Engineering/blob/main/README.md).
These are tool-friendly instructions, not a claim that every note was verified.
The selected source commit and its local README remain authoritative.

- Notes and learning material are in French. A note teaches one concept.
- Notes have a title, plain-text `Tags:` on line 2, an optional existing
  `Vérifié le :` date, and a `<!-- summary: ... -->` comment followed by two blank
  lines. They do not use YAML frontmatter.
- A flashcard consists of a question, a standalone `?`, and an answer. Cards are
  separated by `---`. Preserve `<!--anki:...-->` identifiers in questions and
  `<!--SR:...-->` scheduling comments. Existing IDs preserve revision history.
- Questions must be understandable independently in spaced repetition. Keep
  the same meaning when clarifying references. Do not split, add or remove cards.
- Answers start directly, explain the mechanism and provide a relevant example
  or limit. Avoid duplicating text, adding unsupported facts or arbitrary verbosity.
- `## Mises en situation` precedes the final navigation sections. Preserve its
  cases and their step-by-step answers.
- `## Sources`, when present, precedes `## Connexions`. Existing dated product
  claims and references must not be presented as freshly verified without research.
- `## Connexions` is last. Each connection explains its purpose, is reciprocal,
  and the last connection points to `00-moc-ai-engineering`.
- Obsidian links use unique note stems, such as `[[21-rag-fondamentaux|RAG]]`.
  Verify the target exists and addresses the intended concept before linking.
- README and MOC catalogs are generated by `scripts/sync_catalog.py`. Preserve
  generated blocks; editorial paths outside those blocks are separate content.
- Anki model/deck identifiers and retired-card metadata are outside the scope
  of consistency maintenance. Never change them to silence a failure.
- `make check` runs the repository's structural lint, catalog checks, Ruff,
  mypy, tests and local workshops. The run configuration supplies its Python
  environment. Use the approved `run_checks` action; arbitrary commands are unavailable.
